# my-first-repo

我的第一个仓库 —— 用来学 git 和 GitHub。

## 这个仓库是什么

一个练手用的空仓库。我在这里学着做这几件事：

- 把文件存进来，并且让 git 记住每一次改动
- 改坏了能退回去
- 把东西同步到 GitHub 上

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `README.md` | 就是你正在看的这个文件，用来说明这个仓库是干什么的 |
| `自我介绍.md` | 一个模板，可以填上自己的信息 |

## 常用命令备忘

```bash
git status          # 看看现在有哪些改动还没存档
git add .           # 把改动放进"待存档"清单
git commit -m "备注" # 真正存档，并写一句备注说明改了什么
git log --oneline   # 查看所有存档记录
git pull            # 把 GitHub 上的新东西拉下来
```
